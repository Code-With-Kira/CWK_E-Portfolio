## 1. Governing decisions

The approved TSS establishes Node.js 24 LTS, npm, Next.js, React, TypeScript, Tailwind CSS with custom CSS, Zod, Vitest, React Testing Library, ESLint, and Prettier. It does not prescribe exact dependency versions. This record selects exact candidate versions for the initial package manifest; these are implementation selections, not retroactive TSS requirements.

## 2. Runtime and package manager

- Node.js: `24.x`, enforced by `package.json` engines and `.npmrc`.
- Package manager: npm, as approved by TSS.
- Lockfile: `package-lock.json` must be generated by npm after installation; it is intentionally not hand-authored.
- `save-exact=true` keeps future direct dependency additions pinned.
- `engine-strict=true` prevents installation under an unsupported Node major.

## 4. Compatibility and verification gates

The environment available during this implementation reports Node.js 22.16.0. The approved Node.js 24 runtime is not available in that environment. DNS resolution to `nodejs.org` and `registry.npmjs.org` also failed, preventing runtime installation and npm dependency resolution.

Consequently, the following have **not** been verified:
- npm peer-dependency compatibility across the selected packages.
- successful `npm install` and generated lockfile.
- TypeScript compilation.
- ESLint execution.
- Prettier check.
- Vitest execution.
- Next.js production build.

The exact versions are therefore a committed candidate baseline, not a verified build baseline. After Node.js 24 and registry access are available, run `npm install`, review peer warnings, generate and commit `package-lock.json`, then execute the scripts. Resolve any incompatibilities before CI is added.

## 5. Intentionally excluded for now

- Playwright package and browser installation: defer until the E2E browser setup is selected and verified.
- Resend, Upstash Redis, and GitHub SDK clients: use only after service contracts and integration requirements are finalized; direct service integration may use supported HTTP APIs.
- Vercel Analytics package: defer until deployment and analytics configuration are verified.
- UI component libraries, animation libraries, state-management libraries, and CMS packages: not approved or required by the current baseline.
